# n8n
Workflows live in `n8n/workflows/*.json` (generated by `n8n/build_workflows.py`; CI checks they are in sync). All ship **inactive**.

## One-time setup at https://automation.curiosbot.com
1. Pass Caddy basic auth, create the n8n owner account.
2. Create credentials (Credentials → New):
   - **Header Auth** named `Curiosbot webhook (bearer)`: name `Authorization`, value `Bearer <N8N_WEBHOOK_SECRET>`.
   - **Header Auth** named `Curiosbot ingest (bearer)`: name `Authorization`, value `Bearer <N8N_INGEST_SECRET>`.
   - **SMTP** named `Curiosbot SMTP` (provider details from the owner).
   - Later, owner-connected OAuth: Google Search Console, Salesforce.
3. Import each JSON (Workflows → Import), open it, re-select the credentials, **Activate**.
| File | Trigger | What it does |
|---|---|---|
| 01 lead-captured | app webhook | Internal email to sales; logs run |
| 02 password-reset | app webhook | Emails one-time reset link |
| 03 analytics-ingestion | daily | Search Console → `/api/ingest` |
| 04 alerts-hourly | hourly | App evaluates rules; emails NEW alerts |
| 05 ai-analysis-weekly | Monday | App runs guarded analyst; emails "ready for review" |
| 06/07 product/content published | app webhook | Waits for human approval email before any distribution |
| 08 crm-sync | app webhook | Human approval, then (disabled) Salesforce node |
Set `EXECUTIONS_DATA_PRUNE=true` (already advisable) so reset links are not retained long.
